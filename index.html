Privacy Policy

SoundCloud Minimal Player · Last updated: May 2026

SoundCloud Minimal Player ("the extension") is a browser extension that displays a fullscreen player overlay on SoundCloud. This policy explains what data the extension does and does not handle.

Data We Collect

We collect nothing. The extension does not collect, transmit, store externally, or share any personal data, usage data, or any other information.

What the Extension Does

The extension operates exclusively on soundcloud.com. It reads the page's audio element and track metadata (title, artist name, artwork URL) that SoundCloud already displays on screen, and uses that information solely to render the fullscreen overlay UI. This data never leaves your browser.

Local Storage

The extension uses Chrome's storage.sync API to save your preferences (such as volume level) locally in your browser. This data is stored on your device only and is never transmitted to any server.

Third-Party Services

The extension does not communicate with any third-party services, analytics providers, or advertising networks.

Permissions

The extension requests the following Chrome permissions:

storage — to save your preferences locally.
tabs — to detect whether you are currently on SoundCloud, so the popup can show the correct status.
host_permissions for soundcloud.com — required to inject the player overlay into SoundCloud pages.

Contact

If you have questions about this policy, please open an issue on the extension's GitHub repository or contact the developer directly through the Chrome Web Store listing.
